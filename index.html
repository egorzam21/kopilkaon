О проекте «Копилка»: Жизненный цикл системы

1. Основа проекта

Цели

Сформировать привычку регулярных инвестиций даже при небольших доходах.

Задачи

  • Разработать мобильное приложение/сайт, привязанный к картам/банковским счетам.
  • Автоматически округлять траты.
  • Добавить кэшбэк-бонусы.
  • Встроить функцию «умных инвестиций».
  • Реализовать геймификацию (цели, прогресс-бары).
  • Обеспечить прозрачность и безопасность.

Целевая аудитория

Физические лица 18–45 лет, преимущественно молодёжь и начинающие инвесторы.

4P анализ

Product: Мобильное приложение + веб-платформа с функциями округления, автоИИ, кэшбэком, геймификацией.

Price: Freemium (базовый функционал бесплатно, подписка 199–499 ₽/мес).

Place: Мобильные приложения (iOS, Android), веб-версия, интеграции с магазинами.

Promotion: TikTok, Instagram, Telegram, партнёрства, реферальная система.

SWOT анализ

Сильные: Простота, геймификация, кэшбэк, для молодёжи.

Слабые: Зависимость от банковских API, низкая маржинальность, недоверие.

Возможности: Рост интереса к микросбережениям, партнёрства, криптовалюты.

Угрозы: Конкуренция с банками, изменения законодательства, киберугрозы.

2. Планирование

Техническое задание (основные требования)

  • Система: АС «Копилка» с кэшбэком и автоИИ.
  • Цель: минимизация усилий пользователя, доступность, финансовая грамотность.
  • Подсистемы: Копилка, Кэшбэк, Инвестиции, Личный кабинет, Поддержка.
  • Технологии: Django/Node.js, Kotlin/Swift, PostgreSQL, Redis.
  • Безопасность: 152-ФЗ, TLS, MFA, RBAC, шифрование, пентесты.
  • Этапы: сентябрь – декабрь 2025 (анализ, прототип, кэшбэк, бета-тест).

3. Разработка

Используемые технологии

  • Backend: Django (Python) / Node.js (JavaScript)
  • Frontend (Web): HTML5, CSS3, JavaScript, React
  • Мобильные приложения: Kotlin (Android), Swift (iOS)
  • Базы данных: PostgreSQL (основная), Redis (кеш)
  • API интеграции: Платёжные системы (Tinkoff, Sberbank), биржевые данные, партнёры
  • Хостинг: Облачная инфраструктура (Yandex.Cloud / AWS)

4. Тестирование

Виды тестирования

  • Функциональное: проверка всех функций системы
  • Нагрузочное: тестирование под высокой нагрузкой
  • Интеграционное: тестирование API и внешних интеграций
  • Юзабилити-тестирование: удобство интерфейса для пользователей
  • Безопасность: пентесты, проверка на уязвимости
